# BACKEND FOR CHATAPP (SOFTWARE ARCHITECTURE HCMUT MASTER CLASS)

## Introduction
Backend for chat application for subject assignment of HCMUT class with code base taken from [https://github.com/Longdh57/fastapi-base](https://github.com/Longdh57/fastapi-base)

## Source Library
- [FastAPI](https://fastapi.tiangolo.com/)
- [Postgresql(>=12)](https://www.postgresql.org/)
- Alembic

## Installation
**Manual install with Python and PostgreSQL:**
```
$ sudo -u postgres psql
# CREATE DATABASE fastapi_base;
# CREATE USER db_user WITH PASSWORD 'secret123';
# GRANT ALL PRIVILEGES ON DATABASE fastapi_base TO db_user;

// Clone project & run
$ virtualenv -p python3 .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
$ cp env.example .env      
$ alembic upgrade head
$ uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
**Using Docker** 
- Clone Project
- Run docker-compose
```
$ docker build .
$ docker-compose up -d
```
